Vouch — verify a proof

Paste proof JSON (or the text behind a card's QR), then choose Verify. The check runs entirely in this page — offline, nobody is called, nothing is logged.

A valid signature proves that the listed key signed the statement. It does not independently prove that the statement is true or that an issuer verified it.

Anyone can sign a proof that names any handle with their own key. Paste the handle's manifest from a registry copy you trust (for example vouch-id show @adam) to check the key. The page checks the manifest's own signature but can't see the registry's log, so use a copy you trust (vouch-id audit checks the log). Without a manifest the result is unpinned.
