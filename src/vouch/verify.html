Vouch — verify a proof or presentation

Paste proof JSON (or the text behind a card's QR), or a presentation from vouch-id prove, then choose Verify. The check runs in this page and nothing is logged. The only network call is to a registry URL, if you enter one.

A valid signature proves that the listed key signed the statement. It does not independently prove that the statement is true or that an issuer verified it.

Presentation checks

Anyone can sign a proof that names any handle with their own key. Paste the handle's manifest from a registry copy you trust (for example vouch-id show @adam) to check the key. The page checks the manifest's own signature but can't see the registry's log, so use a copy you trust (vouch-id audit checks the log). Without a manifest the result is unpinned. Presentations need the holder's and vouchers' manifests; with a registry URL the page also reads events.jsonl for withdrawn vouches. Without it, revocation isn't checked.
